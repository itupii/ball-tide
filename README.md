# Ball Tide

Crie um sistema de análise esportiva dos times, puxando todas as estastisticas,  comparações, métricas históricos, tudo que for de relevante para análise, se baseie em sites como por exemplo https://www.r10score.com/,  https://www.sofascore.com/pt,  Flashscore


Quero que seje atualizado em temp real, conecte nas principais api's para puxar os dados esportivos e jogos do mundo inteiro, quero todas as estastíticas, probabilidades possiveis e uma ferrramenta para encontrar padroes de dados da equipe, ele tem que ser atualizado todos os dias com os jogos e placares, assim que sair gol, falta ou alguma acao no jogo twm qur atualizar a plataforma

Conecte com alguma api de casa de aposta que tem api aberta na internet para que possamos simular a montagem de um bilhete, crie uma analise de ia para criacao de bilhete que analise as estastiticas e encontre brechas e padroes
